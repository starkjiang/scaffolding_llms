# Worksheets — the no-code track

These are the Track A materials. You do not need to read or write any Python to
use them. Each worksheet tells you what to type, where to write your answers, and
how to judge what came back.

| `chat-track.md` | all | **No setup needed.** Every lab as paste-ready text — equipment / agronomy example |
| `chat-track-office.md` | all | The same, with an expense-claims desk — no industry knowledge needed |
| `lab-card.md` | — | **Print one per seat.** Every command, on one page |
| `pick-your-example.md` | — | Two parallel examples; pick the one closer to your work |

| Worksheet | Lab | What you will do |
|---|---|---|
| `lab1.md` | Instructions | Write an instruction that holds up, including against a nasty ticket |
| `lab2.md` | Steps | Break your own process into steps and design the checks between them |
| `lab3.md` | Memory | See the difference between answering from memory and answering from documents |
| `lab4.md` | Tools | Watch the assistant look something up instead of guessing |
| `lab5.md` | Trust | Build a scorecard, change one thing, and see what moved |
| `capstone.md` | Capstone | Score the whole assistant and find its weakest link |
| `glossary.md` | — | Every term from the slides, in one line each |
| `examples.md` | — | The six worked examples from the slides, with commands to re-run them |

Every lab works with **either** worked example — the equipment/agronomy one (the default)
or the expense-claims one (`--domain office`), which needs no industry knowledge at all.
See `pick-your-example.md`.

Two ways to do every lab:

- **With the chat tool you already use** (Claude, ChatGPT, Copilot, whatever your
  company allows). Copy and paste from the worksheet.
- **With the one-command tool in this repository**, which needs no editing:
  `python run.py check` to start. See `../SETUP.md`.

Both work. The second one shows you more of what is happening underneath.
